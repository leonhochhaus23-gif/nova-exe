NOVA - Windows app builder

1. Install Node.js (LTS) from https://nodejs.org and keep the default options.
2. Double-click build-nova.bat in this folder. The first time takes a few minutes.
3. When it finishes, the "dist" folder opens.
   Nova-Setup.exe is the installer. Nova-Portable.exe runs without installing.

If it shows an error, take a screenshot of the black window.
